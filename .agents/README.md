# .agents ディレクトリ

LLM エージェントが読むリソースを置く場所。

## git 管理されるもの

追跡対象は次の 2 つだけ。

| パス | 内容 |
|---|---|
| [`../AGENTS.md`](../AGENTS.md) | プロジェクトのエージェント指示 |
| `skills/**/SKILL.md` | プロジェクト固有の skill |

skill は submodule ではなく**通常ディレクトリとして埋め込む**。
submodule だと clone 直後に空ディレクトリになり、skill カタログの走査に
empty として扱われる危険がある。

## git 管理されないもの

このマシンでしか使わない。
壊してよい領域であり、他の開発者にも他のマシンにも渡さない。

| パス | 内容 |
|---|---|
| `memory/` | 作業のための記憶。設計判断・構文の書き方・実測値・不具合の記録 |
| `../.private/` | 作業データ。中間ファイル、調査成果物、発表アーカイブ |

`.git/info/exclude` でローカル管理している。
コミット済み `.gitignore` には書いていない。
別のマシンに展開した内容を晒す必要がないため。

## 情報の行き先

迷ったら `.agents/skills/docs-and-comments/` を読む。
正となる 1 箇所が決まっている。

| 情報 | 置き場所 |
|---|---|
| 作業のための知識（ツールの構文・API の書き方） | `memory/` か skill |
| 設計判断（なぜその方式を選んだか） | `docs/設計/` などの Markdown |
| ロジック（その行が何をするか） | コードのコメント |

設計判断を memory に閉じ込めると、他の開発者が読めない。
追跡できる場所へ移す。
