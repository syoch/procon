# 中間点からの経路開始 (Transient Split)

## 概要

ユーザー指定地点に最も形状的に近いエッジのポリライン上へ垂線を下ろし、投影点でエッジを分割して新しいノードを作成する。分割は SearchGraph 構築直後・Dijkstra 実行直前の一時処理とし、SearchGraph 自体は変更しない。

## 処理フロー

```
1. SearchGraph 完成 (BuildSearchGraph 完了)
2. projectToGraph(point) を start/end それぞれで実行:
   a. 全 FoldedEdge のポリライン (group_nodes から復元) へ垂線距離計算
   b. 最も近いエッジ + 投影点 p_proj を特定
   c. p_proj を含むセグメントを 2 つに分割
   d. new_node を作成、2 本の new_edge に分割
   e. segments[] を 2 つに再分配
   f. group_nodes を 2 分配
3. セッション用グラフで Dijkstra 実行
4. 破棄
```

## 最近傍エッジ判定

- 各エッジのポリラインを segment 列に分解
- 各 segment の内分 t ∈ [0,1] を計算（射影）
  - 0 ≤ t ≤ 1: segment 上に投影
  - t < 0 or t > 1: 端点が最近傍
- 全 segment 中で最小距離のエッジ + segment を採用
- 性能問題化時は spatial index (R-tree 等) を導入

## エッジ分割

- `segments[]` を投影点で 2 分割（各セグメントの `length` を按分）
- `group_nodes` を投影点で 2 分配
- 投影点を新規 `group_nodes` に追加（形状復元用）

## 過渡性

- SearchGraph は変更しない
- セッション用グラフ: `Map<originalEdgeId, [newEdge1, newEdge2]>`
- 破棄時はセッション用グラフを捨てる（次回検索時に再生成）
