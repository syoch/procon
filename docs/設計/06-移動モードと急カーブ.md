# 移動モードと急カーブ

## 移動モード

### 概要

徒歩・自転車・車・バイク・大型トラックの 5 つの移動モードごとに、通れる道・一方通行の扱い・コストの倍率・急カーブの基準を `app/src/lib/mode_profiles.ts`（`MODE_PROFILES`）に一元化する。

- `/api/path-find` に `mode` を指定すると、サーバー側でこの定義に従って探索する
- 画面の車種選択（`parameterVariants`）も `MODE_PROFILES` から作るため、モードの追加・変更は `mode_profiles.ts` だけで完結する
- `mode` を指定しない従来の形式（`parameters` + `wayHighway`）も残す。`mode` と `wayHighway` の同時指定は 400

### 通行可否の判定（`isAccessible`）

OSM の way ごとに、次の順で判定する。いずれかで不可なら、その way はグラフに含めない（`trimOSMDataByMode`）。

| 順 | 判定 | 内容 |
|----|------|------|
| 1 | `highway` 種別 | モードごとの通行可能な種別。舗装されているときだけ通れる種別、タグで明示的に許可されたときだけ通れる種別もある |
| 2 | 自動車専用道路 | `motorroad=yes` は歩行者・自転車は不可 |
| 3 | access 系タグ | 一般 → 具体の順に見て、最も具体的なキーの値を採用する（例: 車は `access` < `vehicle` < `motor_vehicle` < `motorcar`）。`no` / `private` / `agricultural` / `forestry` / `permit` / `military` は不可 |
| 4 | 寸法制限 | 車両のみ。`maxwidth` / `maxheight` / `maxweight` が車両の寸法を下回れば不可。数値でない値（`default` など）は制限なしとみなす |

### モードごとのルール

| | 徒歩 | 自転車 | 車 | バイク | 大型トラック |
|---|---|---|---|---|---|
| 高速道路・`motorroad=yes` | 不可 | 不可 | 可 | 可 | 可 |
| footway / pedestrian | 可 | `bicycle=yes` 等のときだけ可 | 不可 | 不可 | 不可 |
| steps | 可 | 不可 | 不可 | 不可 | 不可 |
| cycleway | `foot=yes` 等のときだけ可 | 可 | 不可 | 不可 | 不可 |
| track | 可 | 可 | 舗装のみ可・割高 | 舗装のみ可・割高 | 不可 |
| service | 可 | 可 | 可・割高 | 可・割高 | 可・割高 |
| living_street | 可 | 可 | 可 | 可 | 不可 |
| 個別の禁止タグ | `foot` | `vehicle`, `bicycle` | `vehicle`, `motor_vehicle`, `motorcar` | `vehicle`, `motor_vehicle`, `motorcycle` | `vehicle`, `motor_vehicle`, `hgv` |
| 一方通行 | 無視 | 従う（`oneway:bicycle` を優先） | 従う | 従う | 従う |
| 急カーブの検出 | しない | しない | する | する | する（下限 20m） |

- 舗装: `tracktype=grade1`、または `surface` が `paved` / `asphalt` / `concrete` / `paving_stones` など（`isPaved`）
- バイクは原付を対象外とし、全てのバイクが高速道路を通れるものとした
- 大型トラックの寸法: 幅 2.5m・高さ 3.8m（保安基準 第 2 条の上限）、総重量 20t（仮の値）

### 一方通行

- グラフ構築（`map_loader/osm.js`）は `oneway` タグだけを見て通行方向を決める
- 自転車は `oneway:bicycle` があれば、`trimOSMDataByMode` で `oneway` をその値に置き換える（元データは書き換えず複製する）。`oneway=yes` かつ `oneway:bicycle=no` の道は双方向に通れる
- 徒歩は探索時に一方通行を無視する（`PathFindOptions.ignoreOneway`）

### 割高な道（`highwayCostFactor`）

幅が分からない道を抜け道に使わないよう、区間の距離に倍率を掛ける（`PathFindOptions.highwayCostFactor`）。そこしか道が無いとき（目的地の手前など）だけ通る。

| モード | 倍率 |
|--------|------|
| 車・バイク | track ×2、service ×2 |
| 大型トラック | service ×2 |

国土地理院の幅員区分を取り込んだ後は、幅にもとづく判定に置き換える予定。

### 根拠

| 内容 | 根拠 |
|------|------|
| 歩行者・自転車・原付・125cc 以下の二輪は高速道路・自動車専用道路を通行不可 | 道路法 第 48 条の 11、高速自動車国道法 第 17 条 |
| 自転車は軽車両として一方通行に従う | 道路交通法 |
| 自転車の歩道通行は「自転車歩道通行可」の標識がある場合（OSM では `bicycle=yes` 等） | 道路交通法 |
| 大型トラックの幅 2.5m・高さ 3.8m | 道路運送車両の保安基準 第 2 条 |
| 大型貨物自動車等通行止め = `hgv=no` | OSM Wiki `JA:Key:hgv` |
| access 系タグの階層 | OSM Wiki `JA:Key:access` |

## 急カーブ検出

### 概要

経路の「道の途中のカーブ」のうち、減速が必要な急なものを検出して返す（`app/src/lib/sharp_turn.ts`）。交差点での右左折は対象外。

### 考え方

曲がり角の大きさだけでは危険度を判定できない（同じ 90° でも 10m で曲がるのと 200m かけて曲がるのでは違う）。そこで曲線半径を推定する。

```
R = L / θ
  L: カーブの長さ [m]
  θ: カーブ全体の曲がり角 [rad]
```

OSM の道は折れ線なので、同じ向きに続けて曲がる頂点（間隔 30m 以内）を 1 つのカーブにまとめてから R を求める。半径 R の円弧を間隔 d の折れ線で描くと各頂点の曲がり角は d / R になるため、L / θ は折れ線の描き方（頂点の数）によらず元の円弧の半径に近い値になる。

- 頂点が複数: L = 最初と最後の頂点の間の長さ
- 頂点が 1 つ（角）: L = 前後の区間の半分ずつ（各 15m まで）

### 判定条件

次の両方を満たすカーブを急カーブとする。

```
θ ≥ 50°
R < max( min(道路の最小曲線半径, 30m), モードの下限 )
```

道路の最小曲線半径は道路構造令 第 15 条の縮小値（視界スコアと同じ表）。

| highway | 設計速度の目安 | 最小曲線半径 |
|---------|---------------|-------------|
| motorway | 120 km/h | 570m |
| trunk | 100 km/h | 380m |
| primary | 80 km/h | 230m |
| secondary | 60 km/h | 120m |
| tertiary | 50 km/h | 80m |
| unclassified / *_link | 40 km/h | 50m |
| residential | 30 km/h | 30m |
| living_street / service / track | 20 km/h | 15m |

- 上限 30m（設計速度 30km/h の最小曲線半径）で打ち切り、「おおむね 30km/h 以下に減速が必要なカーブ」だけを拾う
- 大型トラックの下限 20m は、最小回転半径 12m（保安基準 第 6 条）に余裕を見た値

### 危険度

| level | 条件 | 表示 |
|-------|------|------|
| `sharp`（急カーブ） | R < 20m | 赤 |
| `caution`（注意） | 20m ≤ R | オレンジ |

20m は設計速度 20km/h（15m）と 30km/h（30m）の間の目安。

### 道を区切る点

次の点ではカーブをまとめず、そこでの曲がりも拾わない。

| 点 | 理由 |
|----|------|
| 探索グラフの交差点（`MapVCrossEdge`） | 交差点での右左折は対象外 |
| 元データの交差点（`collectRoadJunctions`） | モードで通れない道（track など）との交差点は探索グラフでは交差点にならないため、絞り込む前のデータで判定する。車両が通る道が 3 方向以上つながる点を交差点とする（歩道・駐車場の出入口 `service=driveway` 等は数えない） |
| 地図データの取得範囲の外 | 範囲外の道は取得されておらず、交わる道が見えないため |

### 仮の値

| 値 | 定数 |
|----|------|
| 合計角度の下限 50° | `MIN_TOTAL_ANGLE_DEG` |
| 半径の上限 30m | `SHARP_RADIUS_CAP_M` |
| 急カーブ / 注意の境 20m | `SHARP_LEVEL_RADIUS_M` |
| 頂点 1 つのカーブで前後の区間から長さに含める上限 15m（`MAX_GAP_M` 30m の半分。半径を小さめに見積もる＝過剰検知寄り） | `MAX_HALF_SEGMENT_M` |
| 大型トラックの下限 20m | `MODE_PROFILES.truck.sharpTurnMinRadius` |

## 到達できない場合

`/api/path-find` は、経路を返せない場合に `found: false` と理由を返す。

| reason | 状況 |
|--------|------|
| `BEGIN_UNREACHABLE` | 出発地から 200m 以内に、このモードで通れる道が無い |
| `END_UNREACHABLE` | 目的地から 200m 以内に、このモードで通れる道が無い |
| `NO_ROUTE` | 一方通行などで、始点から終点にたどり着けない |

- 始点・終点は最大連結成分（最も大きくつながった道路網）の道にだけ吸着する。孤立した敷地内の道などに吸着して経路が見つからなくなるのを防ぐため
- 吸着先が 200m（`MAX_SNAP_DISTANCE_M`）より遠い場合は、間違った場所への経路を黙って返さず `found: false` とする
- 探索範囲は、始点・終点を囲む 1/64° の格子に、周りに 1 マス分の余白を足した範囲とする（`getBoundaryBox`）。余白が無いと、範囲の外を回る道（山道など）が切れて道路網から切り離される
